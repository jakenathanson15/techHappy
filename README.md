## Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- Package manager (e.g., `npm`, `pnpm`, or `yarn`)

### Installation
```bash
# Clone the repository
git clone https://github.com/<owner>/techHappy.git
cd techHappy

# Install dependencies (once initialized)
npm install
```

### Running Locally
```bash
npm run dev
```
